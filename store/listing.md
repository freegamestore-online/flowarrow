## Description

Flowarrow is a calm puzzle about flow. Every arrow on the board points one way. An arrow can slide off the edge only when nothing stands in its path. Work out the order, clear the whole board, and do it in as few mistakes as you can.

- Sixty levels, from small 4×4 boards up to 10×10 grids.
- A new daily board every day, the same for everyone on the same UTC date.
- Tap a blocked arrow and it counts as a mistake. Three mistakes end the level, but you can always restart at once.
- Undo any slide, and use one hint per level to find the next free arrow.
- Stars for each cleared level: fewer mistakes and a faster clear earn more.
- Light and dark mode, following your system setting. Animations turn off when reduced motion is on.
- Works offline once loaded. Installs to your home screen.

Every level is checked by a solver before it ships, so every board can be cleared.
